# Still Waters

Original instrumental written for Mind Soul & Body. The project owns this recording.

It does not quote or adapt the melody, chords, or hook of any existing song. `compose.py` generates it with additive synthesis only (no samples): a D natural minor string pad, a low drone, and a sparse piano line at 64 BPM. The loop is 60 seconds.

`still-waters.ogg` is the preferred file. `still-waters.mp3` is the fallback for browsers that cannot play Vorbis, including iOS Safari and some Android WebViews. Playback in the app stays off until the header speaker is turned on.
